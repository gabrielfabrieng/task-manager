Requisitos do Projeto

a)      Desenvolver uma aplicação web de gerenciamento de tarefas (To-Do List) com funcionalidades avançadas.

b)      Criar e gerenciar categorias para organizar as tarefas.

c)      Compartilhar tarefas com outros usuários.

d)     Criar e testar uma API externa para integração ao projeto.

e)      O usuário consiga criar uma conta e fazer login.

f)       O usuário consiga marcar tarefas como concluídas ou não concluídas.

g)      Filtragem de Tarefas.

h)     Paginação de Tarefas.
